## Admin 업무 배치

- 웹은 상품·접수·정산의 기존 여러 패널을 유지한다. Sales의 480px 모바일 폭을 PC 업무판 전체에 강제하지 않는다.
- 웹 업무 4축, 폰 업무 5걸음은 Admin의 기존 정보 구조다. Sales의 통화/관심/문자/설정 명칭을 복사하지 않는다.
- 상세/신규에서 이동 탭과 실행바를 두 줄로 쌓지 않는다.
- 주행동은 실제 페이지의 기존 서버 액션을 사용한다. 가짜 저장이나 별도 정적 앱을 만들지 않는다.
- Sales의 글꼴 미세 단계 전부를 자동 복사하지 않는다. Admin의 정보 위계 18/14/12와 패널/목록 구조는 유지하고, 공통 셸·컨트롤부터 Sales에 맞춘다.
- 색상은 Sales 밝은 기본형을 적용했다. Sales 전체 다크 테마를 Admin에 이식한 것으로 간주하지 않는다.
