# UI 규격 — freepass-admin

최종: 2026-09-16 · 기준 파일: `docs/ui/mockups/admin-shell.html`

> 이 문서는 **재는 자**다. 새 화면을 만들 때 여기 없는 높이·폭·여백을 새로 만들지 않는다.
> 어긋나면 **이 문서를 고쳐서** 최신으로 둔다. 딴 데 새 규격을 만들지 않는다.

---

## 0. Shell Baseline — 웹/모바일 기본 틀

이 절은 화면 디자인보다 먼저 적용한다.

### Mobile
- HTML은 반드시 `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` 를 가진다.
- `#mapp`은 실제 device width 100%와 `100dvh`를 사용한다. PC 기준 폭을 모바일에서 축소 렌더링하지 않는다.
- 앱바 52 / 입력 38 / 목록행 64 / 실행 44 토큰을 유지한다.
- 하단 탭은 기존 **상품 · 접수 · 실적 · 설정** 4개다.
- 페이지 action이 있으면 기존 `.mact`가 탭바 바로 위에 붙는다.
- LIST → DETAIL → WORK 전환을 유지하며 PC panel을 세로로 쌓지 않는다.

### Web
- 왼쪽 rail 기본 200, 접힘 54.
- 본문은 기존 **목록 7 : 상세 3**, 상세 최소 360px.
- 제목줄 / 도구줄 / 발치줄은 각 38px.
- 표 row 34, table header 30.
- 기존 splitter로 목록/상세 및 좌측 상하 pane 비율 조절 가능.

### AI Core
AI Core는 위 shell을 다시 디자인하지 않는다.
기존 UI에 `data.search-discovery`, `data.master-detail`, `navigation.bottom-action`, `navigation.bottom-nav`, `data.variant-selector` 계약만 매핑한다.

## 1. 눈금 — 높이는 **넷**뿐이다

| 토큰 | 값 | 무엇 | 쓰는 곳 |
|---|---|---|---|
| `--h-chip` | **22** | 딱지·상태·줄 안 단추 — 누르지만 «읽는» 것에 가깝다 | `.st` `.tok` `.btn.sm` `.railtoggle` |
| `--h-ctl` | **30** | 입력칸·도구 단추 — 손이 «고르는» 것 | `.fd input` `.gs input` `.sb` `.tb` `.memo` `table.g th` |
| `--h-row` | **34** | 표 한 줄 — 눈이 «훑는» 것 | `table.g td` `.rail nav button` `.menu button` |
| `--h-act` | **38** | 실행 단추 · **띠 높이** — 손이 «누르는» 것 | `.btn` `.mbtn` `.ph` `.bar` `.pf` `.kpi` `.fld input` |
| `--h-top` | **46** | 전역 상단바 · 시트 머리 | `.topbar` `.sbox .sh` |

★**띠 셋이 같은 높이(38)** 다 — 판 제목줄 `.ph` · 도구줄 `.bar` · 발치줄 `.pf`.
판을 여럿 세워도 줄이 맞는다. 도구줄은 조건 토큰이 붙어 줄이 늘 때만 위아래 4px를 더한다.

★**26·28·32·36·40·44 를 새로 만들지 않는다.** 2026-09-16 실측에 여섯 가지가 섞여 있었다.
눈이 가르지도 못하는 차이를 여섯 벌 두면 규칙만 늘고 화면은 그대로다.

## 4. 폭

| 토큰 | 값 | 무엇 |
|---|---|---|
| `--w-rail` | **200** | 왼쪽 업무 메뉴 |
| `--w-rail-mini` | **54** | 접었을 때 — 아이콘만 |
| `--w-find` | **250** (≤1400px 에서 **190**) | 판 안 검색칸 |

★**검색칸은 «치는 만큼»** 이다. 판 폭을 다 먹으면 걸린 조건이 아랫줄로 밀리고,
그만큼 목록이 내려가 첫 화면에 상품이 덜 보인다.

### 4-1. 판 나눔 — **목록 7 : 상세 3**

```
┌─ 200 ─┬───────── 7 ─────────┬─ 6 ─┬──── 3 ────┐
│ 레일   │ 상품목록             │  ⇔  │           │
│       ├──────── 6 ──────────┤     │  상세      │
│       │ 접수목록             │     │  (하나)    │
└───────┴─────────────────────┴─────┴───────────┘
```

- 목록은 표 칸 예닐곱을 안 자르는 것이 먼저다. 상세는 «읽는 칸»이라 좁아도 된다
- 상세 최소 **360px**. 그 아래로는 못 줄인다
- 가르는 선 둘 다 끌 수 있고 **두 번 누르면 기본값**으로 돌아온다
- 실측(1680px): 목록 1015 · 상세 435 · **2.33 : 1** = 7:3

## 5. 판 짜임 — 넷 다 같은 꼴

```
┌──────────────────────────────────────┐
│ 제목 · 건수 · (빈칸) · 그 판의 주 도구  │  .ph   38
├──────────────────────────────────────┤
│ 검색(250) · 필터칩 · 걸린 조건         │  .bar  38
├──────────────────────────────────────┤
│                                      │
│  표 (줄 34 · 머리 30 · 머리 고정)      │  .pb   남는 만큼
│                                      │
├──────────────────────────────────────┤
│ 그 판이 지키는 규칙 한 줄               │  .pf   38
└──────────────────────────────────────┘
```

## 6. 단추 — 자리로 말한다

```
┌──────────────────────────────────────┐
│ 메모 입력칸                    (30)    │
│ [⋯] [보조]        (빈칸)     [■ 주]   │  38
└──────────────────────────────────────┘
```

- **주 행동은 하나**만 채운 색(`--key`). 지금 단계에 따라 글자가 바뀐다
- **보조**는 테두리만
- ★**위험한 것은 색이 아니라 «자리»로 뗀다** — 취소·삭제는 `⋯` 안에만 둔다.
  빨간 단추를 늘 띄워 두면 매일 보는 사람은 그걸 곧 무시한다
- 주 단추 최소 폭 **136**

## 7. 색 — 하루 여덟 시간 보는 색

내부 프로그램이다. B2C 색을 그대로 쓰면 오후에 눈이 아프다.

| | 값 | 왜 |
|---|---|---|
| 판 | `#fafbfc` | ★순백을 크게 깔지 않는다 — 반사광이 세다 |
| 글자 | `#252b31` | ★순검정에서 뗀다 — 흰 바탕에서 획이 번진다 |
| 강조 | `#3d6b8e` | 채도가 높으면 초점이 계속 당겨진다 |
| 좋음/주의/나쁨 | `#45775d` / `#856b3a` / `#94534b` | 전부 한 단 낮춤 |

★**상태 딱지는 바탕색을 안 쓴다.** 테두리 1px + 글자색만.
표에 딱지 스무 개가 파스텔로 깔리면 정작 봐야 할 「이슈」가 안 보인다.

★**고른 줄**은 아주 옅은 틴트 + **왼쪽 3px 막대**로만 말한다(레트로가 쓰던 방식).

## 9. 폰 — 한 단 크게, 그러나 **같은 자리**

| 토큰 | 값 |
|---|---|
| `--m-bar` | **52** 앱바 |
| `--m-ctl` | **38** 입력칸·아이콘 단추 |
| `--m-row` | **64** 목록 한 줄 (손가락) |
| `--m-act` | **44** 실행 단추 |

★**PC 의 판 셋을 «압축»하지 않는다.** 폰은 **페이지가 바뀐다**:

```
목록 ──▶ 상세 ──▶ 접수폼 ──(저장)──▶ 접수목록
 ◀── 뒤로 ──┘
```

- 위: `← 뒤로 · 제목/부제 · 우측 액션` (목록에서는 뒤로가 없다)
- 아래: 탭 **넷** — `상품 · 접수 · 실적 · 설정` + 배지, `safe-area` 여백
- 실행 띠는 **탭바 위**에 붙는다
- ★Offer 고르기는 표가 아니라 **큰 카드 단추** — 폰에서 표는 못 누른다

### 9-1. 페이지 수

지금 **8장** + 시트 1

| 탭 | 페이지 |
|---|---|
| 상품 | 상품목록 · 상품상세 · 신규접수 |
| 접수 | 접수목록 · 접수상세 |
| 실적 | 실적목록 · 실적상세 |
| 설정 | 설정 |
| (시트) | 세부필터 |

아직 안 만든 것 **6장** — 청구목록/상세 · 지급목록/상세 · 전자계약목록/상세.
**다 하면 15장**이고 그중 11장이 「목록↔상세」 쌍이라 한 틀로 찍어낸다.

## 10. 재는 법

브라우저 콘솔에서 자로 잰다. 눈으로 보지 않는다.

```js
const H = s => Math.round(document.querySelector(s).getBoundingClientRect().height);
({ 제목줄:H('.ph'), 도구줄:H('.bar'), 발치줄:H('.pf'), 표줄:H('table.g tbody td'),
   실행단추:H('.dact .btn.go'), 검색칸:H('.fd input') })
// → 38 · 38 · 38 · 34 · 38 · 30 이어야 한다
```
