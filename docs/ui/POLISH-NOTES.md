# 화면을 «산뜻하게» — 찾아보고 온 것과, 그중 지킨 것

> 대표 2026-09-17 「ui ux를 좀 세련되게 못하나?? 산뜻하게??」 · 「우중충 하지 않게」
> 「야 단편적으로 이렇게도 디자인을 하는데」(뮤카 구독사업 운영 허브)
> 「꼭 저렇게 하라는게 아니라 좀 어딘가 학습좀 해보고 와」
> 「야 적어도 명확하게 목록라인이나 이런건 있어야 하는데 그런것도 없고…」

## 1. 찾아본 데서 건진 «쓸 수 있는» 규칙

| 규칙 | 어디서 | 우리가 |
|---|---|---|
| 표의 줄 높이 **36px** · chrome 은 거의 없이 | Linear | ✅ `--h-row:36px` |
| 돈은 **오른쪽 정렬 + 고정폭 숫자**(tabular-nums) | Stripe 데이터 표 | ✅ `td.r`·`td.n` 에 걸었다 |
| 격자선은 **muted 하되 «둔다»** · hairline 0.5~1px 저알파 | Stripe · 공통 | ✅ 아래 §2 |
| 카드 모서리 **8~12px** · 안쪽 여백 **24px** 로 «일정하게» | 공통 | ◐ 모서리 12 · 여백은 16 (밀도 때문) |
| 글자 크기 **4~6 단** 을 넘기지 않는다 | 공통 | ◐ 지금 7단 — 줄여야 한다 |
| **틴트 뉴트럴** — 순회색·순검정을 안 쓴다 | 공통 | ✅ 처음부터 그랬다 |
| 상태 여섯을 다 정의: default·hover·focus·active·disabled·loading | 공통 | ◐ loading 이 없다 |

★기사들이 하나같이 **「hex 를 베끼지 마라」** 고 적었다 —
「Linear 가 회색을 «어떻게 쓰는지» 가 중요하지 그 값이 중요한 게 아니다」.
그래서 색은 베끼지 않고 **우리 밝기·대비 기준**으로 다시 잡았다.

## 2. ★내가 저지른 것 — 「옅게」 를 「없이」 로 갔다

산뜻하게 한다고 선을 걷었더니 **표의 줄이 안 보이게 됐다.**
여덟 칸을 가로질러 한 줄을 읽는 표에서 선이 없으면 눈이 줄을 놓친다.

```
잘못     --line:#e9edf1   (거의 안 보임)  · 얼룩무늬도 걷음
바로잡음 --line:#e3e8ee   본문 선
         --line-row:#dde4ea  ★표의 «줄 선» — 본문보다 한 단 진하다
         머리줄 밑은 1.5px --line-2  — 여기가 «갈리는» 자리다
         마지막 줄 밑선은 판 바닥과 겹치므로 뗀다
```

**산뜻함은 선을 «없애는» 게 아니라 «얇고 옅게 두는» 것이다.**

## 3. 뮤카 화면에서 가져온 것 / 안 가져온 것

| | |
|---|---|
| 가져옴 | 민트 강조색 · 넉넉한 여백 · 연한 틴트 카드 · 흰 판을 그림자로 띄우기 |
| 안 가져옴 | 큰 헤드라인(24px+) · 번호 배지 · 넓은 카드 간격 — **그건 «읽는 문서» 의 리듬**이고 우리는 하루 여덟 시간 «훑는 데스크» 다 |

★파랑(`#1766b3`)에서 민트(`#0c7d73`)로 옮긴 까닭 —
파랑은 회색기가 섞이면 바로 칙칙해지는데, 민트는 밝기를 낮춰도 맑게 남는다.
**칙칙함(회색 섞기)과 차분함(밝기 낮추기)은 다른 일이다.**
되돌리려면 토큰 네 줄만 갈면 된다.

## 4. 아직 안 한 것 — 숨기지 않는다

- **글자 크기가 7단** 이다. 4~6단으로 줄여야 한다
- **loading 상태가 없다** — 여섯 미세상태 중 하나가 빈다
- **빈 상태**가 밋밋하다 (Linear 은 여기에 공을 들인다)
- **키보드 길**이 `/`·`[`·`Esc` 뿐이다
- 레트로 결의 대비 미달 10여 곳이 남아 있다
