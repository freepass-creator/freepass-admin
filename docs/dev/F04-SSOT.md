## 2. ★「수수료표」가 내 물음의 답이었다

어제 저는 「요율 칸에 정액이 섞여 있다 — 한 칸에 뜻이 둘이다」라고 적었다.
**섞인 게 아니라 셈법이 일곱 가지였다.**

| 셈법 | 줄 | 무엇 | 기계가 내나 |
|---|---|---|---|
| `대여료×기간` | 80 | 요율 (0.0475 · 0.0375 · 0.0325 · 0.0225) | 예 |
| `정액` | 23 | 600,000 / 500,000 꼴 | 예 |
| `차량가액` | 19 | 신차 선출고 — 차량가액 × 3.5% / 3.0% | 예 |
| `범위` | 20 | 「최대 9%」 | ★**사람이 정한다** |
| `구독료+정액` | 5 | 「12개월구독료 100% + 30만」 | ★**사람이 정한다** |
| `조건분기` | 2 | | |
| `한달렌탈료` | 1 | | |

```
기계가 낼 수 있나 —  예 122 · ★사람이 정한다 28 · 빈칸 6
```

★**「사람이 정한다」가 28줄이다.** 이걸 기계가 계산하려 들면 틀린다.
SSOT 는 이 구분을 **그대로** 담아야 한다 — 「모르는 것」이 아니라 「사람 몫」이다.

그리고 대표가 「아 웰릭스 신차인가보네」 하신 것이 여기서 확인된다 —
신차는 `차량가액` 기준이거나 `범위`(최대 9%)라 **요율표의 재렌트 요율과 아예 다른 축**이다.

## 3. SSOT 를 어떻게 세우나

```
f04/
 ├ feeTable   156   ★셈법 정본. 열쇠 = 공급사 + 갈래 + 형태 + 계약기간
 ├ rows       568   실적 한 벌 (접수 95 + 완납 378 + 분납 48 + 취소 47)
 │                  열쇠 = 차량번호 + 접수일 · 「어느 탭에서 왔나」를 상태로 남긴다
 ├ progress   432   사람 작업 흔적 (정산 진행) — rows 와 차량번호로 잇는다
 ├ vehicles   465   차량대장 — 차 이름의 정본
 └ goods      360   _상품 — 차량가액·기간별
```

### 지킬 것

1. **읽은 줄 = 실은 줄 + 보류한 줄.** 조용히 사라지는 줄 0
2. **자리로 읽지 않는다** — 열 이름으로 붙인다. 원본은 열 자리가 흔들린다
3. **빈칸을 0 으로 만들지 않는다**
4. ★**청구월은 `청구년` + `청구월` 두 칸에서 세운다.** ERP5 의 `"2026-09"` 는 파생값이다
5. ★**날짜로 변한 값을 되돌린다** — 시트가 「2026-08」을 `46235` 로 바꿔 놨다
6. **파생 탭은 안 담고 대조에만 쓴다**
7. **두 번 돌려도 같다**(멱등)
